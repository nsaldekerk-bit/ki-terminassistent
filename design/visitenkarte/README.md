# Visitenkarte westfaliadigital

Arbeitsdateien für die Visitenkarte, 85 × 55 mm (Trimmgröße, ohne Beschnitt),
gezeichnet mit 96 px pro Zoll → 321 × 208 px.

- `Main.dc.html` / `RueckseiteA.dc.html` — Richtung A, Stahl & Signal (dunkel)
- `VorderseiteB.dc.html` / `RueckseiteB.dc.html` — Richtung B, Papierweiß
- `VorderseiteC.dc.html` / `RueckseiteC.dc.html` — Richtung C, Vollton Orange
- `canvas.json` — Anordnung der Artboards auf der Canvas
- `visitenkarte-westfaliadigital.html` — daraus erzeugte Canvas-Datei

Schriften: Archivo (Wortmarke, Namen) und IBM Plex Mono (Kontakt, Labels).
Farben: #0f1216 Anthrazit, #ff7d33 / #ec6a1e Orange, #f6f4f1 Warmweiß.

Angaben in eckigen Klammern sind Platzhalter und müssen vor dem Druck ersetzt werden.
